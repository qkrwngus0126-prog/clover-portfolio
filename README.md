# 세잎 아카이브

네잎클로버로 빽빽한 들판을 헤집어 숨은 세잎클로버 세 개를 찾는 포트폴리오 사이트입니다.
세 개의 세잎은 세 가지 관심사, 공간과 인테리어 · 라이프스타일 · 서비스 분석입니다.

- `index.html` 하나로 된 사이트입니다. 브라우저로 바로 열면 됩니다.
- 클로버 들판은 코드(Canvas)로 그렸습니다.
- 기록 글 페이지는 `posts/` 폴더에, 글에 쓰는 사진은 `posts/images/`에 있습니다.
- 첫 기록(도면이 있어 운이 좋았던 이사)만 실제 글이고, 나머지 5편과 연락처, 소개 편지 서명은 아직 예시 내용입니다.
