# 세잎 아카이브

네잎클로버로 빽빽한 들판을 헤집어 숨은 세잎클로버 세 개를 찾는 포트폴리오 사이트입니다.
세 개의 세잎은 세 가지 관심사, 공간과 인테리어 · 라이프스타일 · 서비스 분석입니다.

- `index.html` 하나로 된 사이트입니다. 브라우저로 바로 열면 됩니다.
- 클로버 들판은 코드(Canvas)로 그렸습니다.
- 기록 글 페이지는 `posts/` 폴더에, 글에 쓰는 사진은 `posts/images/`에 있습니다.
- 실제 기록 글 목록과 작업 규칙은 [`CLAUDE.md`](CLAUDE.md)에 있습니다. 예시 카드, 연락처, 소개 편지 서명은 아직 예시 내용입니다.

## saeip (예전 세잎 들판, `happiness/`)

- **saeip.com으로 이사했어요.** 코드는 [qkrwngus0126-prog/saeip](https://github.com/qkrwngus0126-prog/saeip) 저장소에 있어요.
- `happiness/` 폴더에는 예전 주소로 들어온 사람(공유 링크 포함)을 saeip.com으로 넘겨 주는 안내 페이지만 남겨 뒀어요.

## Fl.own (`bouquet/`)

꽃을 한 송이씩 골라 꽃다발을 만들고 꽃말 엽서까지 준비해 보는 시연용 사이트입니다. `bouquet/index.html`을 브라우저로 열면 됩니다.

- 꽃·꽃말·포장지·추천 조합은 [`bouquet/data.js`](bouquet/data.js) 한 파일에 모여 있습니다.
- 여는 법, 그림 넣는 법은 [`bouquet/README.md`](bouquet/README.md)에 있습니다.
