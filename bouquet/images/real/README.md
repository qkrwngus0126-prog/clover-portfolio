# AI 실사 미리보기 이미지 넣는 곳

`data.js`의 추천 조합(recipes)마다 실사 이미지 한 장씩입니다.
파일이 없으면 사이트에 "이 조합의 실사 미리보기는 준비 중이에요"라고 나와요.

- 형식: JPG(또는 PNG — 이 경우 `data.js`의 `photo` 이름도 .png로 바꾸기)
- 비율: **세로 4 : 5** (예: 1200 × 1500 px). 다른 비율이면 가운데를 기준으로 잘려 보여요.
- 구도: 꽃다발이 화면 가운데, 위아래로 조금 여백. 배경은 밝은 크림·미색 계열이면 사이트와 잘 어울려요.
- 각 조합에 적힌 꽃·색·포장지·리본과 최대한 비슷하게 만들어 주세요.
