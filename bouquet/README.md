# Fl.own

꽃을 한 송이씩 골라 나만의 꽃다발을 만들고, 꽃말을 모은 엽서까지 준비해 보는 시연용 사이트입니다.
실제 주문·결제·꽃집 연결은 없습니다.

- **인터넷 주소로**: 이 브랜치가 `main`에 합쳐지면 GitHub Pages에서
  `https://qkrwngus0126-prog.github.io/clover-portfolio/bouquet/` 로 열립니다.

## 사용 흐름

처음에는 연필로 그린 꽃집 한 채가 나와요. 색은 꽃에만 있어요. 가게 문 두 짝이 두 가지 길이에요. **왼쪽 문은 직접 고르기, 오른쪽 문은 추천 받기**예요. 커서를 올리면 문이 살짝 열려요. 휴대폰에서는 화면 아래 버튼으로도 고를 수 있어요. 왼쪽 위 로고를 누르면 첫 화면으로 돌아가요.

- **직접 고르기**: 아래 1~5단계를 차례로 밟아요.
- **추천 받기**: 질문 7개(받는 사람, 나이대, 성별, 어떤 날, 마음, 분위기, 색감)에 하나씩 답하면 어울리는 꽃다발 3개와 가장 가까운 대표 조합을 보여 줘요. 질문은 모두 건너뛸 수 있고, 위에 쌓인 답을 누르면 그 질문으로 돌아가요. 고른 조합은 1단계로 담겨서 그대로 고칠 수 있어요.

1. **꽃 고르기** — 메인 꽃 / 채움 꽃 / 잎 소재로 나뉜 목록에서 색을 고르고 담기. 꽃말이 같이 보여요.
2. **포장** — 포장지와 리본을 고르면 바로 꽃다발에 입혀져요.
3. **실사 보기** — 대표 조합과 똑같으면 AI 실사 이미지를, 아니면 안내를 보여 줘요.
4. **엽서** — 담은 꽃의 꽃말로 문구를 자동으로 만들고, 엽서 위에서 바로 고칠 수 있어요.
5. **완성** — 꽃다발 + 꽃말 + 엽서를 한 장의 카드로. 인쇄하거나 PDF로 저장할 수 있어요.

꽃다발을 만드는 중에도 오른쪽 위 **추천 받기**로 질문 화면을 열 수 있어요.
담은 꽃은 브라우저에 저장돼서 새로고침해도 남아 있어요.

## 무엇을 어디서 고치나

| 고치고 싶은 것 | 파일 |
|---|---|
| 서비스 이름, 꽃, 꽃말, 색, 포장지, 리본, 마음, 추천 조합, 엽서 기본 문구 | `data.js` (이 파일 하나만 고치면 돼요) |
| 추천 받기 질문과 보기, 보기마다 더하는 점수 | `data.js`의 `quiz` |
| 꽃마다 분위기(`vibes`)·어울리는 마음(`moods`), 색마다 색감(`tones`) | `data.js`의 꽃 목록과 색 팔레트 |
| 꽃 그림 | `images/flowers/` 폴더에 PNG 넣기 → 규칙은 [images/flowers/README.md](images/flowers/README.md) |
| AI 실사 이미지 | `images/real/` 폴더에 JPG 넣기 → 규칙은 [images/real/README.md](images/real/README.md) |
| 첫 화면 그림 | `images/intro.webp` (AI로 그린 꽃집 스케치에 꽃만 색을 입힌 그림, 1672×941). 흘러가는 구름 두 개는 `images/intro-cloud-1.png`, `intro-cloud-2.png`로 따로 떼어 두었어요. 그림을 바꾸면 `css/style.css`의 문·구름 위치(%)도 같이 맞춰야 해요 |
| 색·글씨·여백 같은 디자인 | `css/style.css` 맨 위 `:root` 부분 |
| 꽃다발 위 큰 영문 제목 (ONE STEM. AT A TIME. 등) | `js/app.js`의 `TITLES` |

`js/` 폴더는 움직임과 화면을 만드는 코드라 평소에는 건드리지 않아도 됩니다.

- `js/art.js` — 코드로 그린 꽃·포장지·리본. 수채화처럼 번진 색(`fl-wash`) 위에 연필 선을 얹어 그려요
- `js/recommend.js` — 추천 받기 답을 점수로 바꿔 꽃다발 3개를 만드는 곳
- `js/bouquet.js` — 꽃다발 배치와 흔들림, 커서 쪽으로 살짝 기울어지는 입체 효과(대표 인터랙션)
- `js/app.js` — 단계 이동, 목록, 엽서, 추천

## 꽃말 확인

꽃말은 출처마다 조금씩 다르게 전해집니다. `data.js`에서 `// 확인 필요`라고 적힌 꽃(스프레이 장미 일부 색, 분홍 아네모네,
왁스플라워, 마트리카리아, 루스커스, 레몬잎, 미스티블루)은 제출 전에 한 번 확인해 주세요.
